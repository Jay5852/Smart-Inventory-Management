📡 Network Settings

Configure the WiFi credentials that ESP32 devices will automatically fetch when they connect to an open network.

Device WiFi Configuration

Enter the WiFi network you want your Gate Reader and GPS Tracker to connect to. Add one or more company WiFi profiles and the device will store them in flash permanently.

How It Works

  1. Enter one or more WiFi SSID and Password pairs above and click Save.
  2. On the ESP32 Gate Reader, hold the SELECT button for 3 seconds.
  3. Scan the Admin Card to unlock the menu.
  4. Select "Fetch WiFi Config" from the menu.
  5. The device will connect to a network, download the profiles, store them in flash, and reconnect securely.
